# LHH FESCO｜让用工问题，有据可循

LHH 原片第七版用一件试用期考核问题串联整片。观众依次看到 HR 遇到的情况、提出的问题、可核对的材料，以及需要进一步判断时怎样联系顾问。

## 13 段成片分镜

| 时间（秒） | 镜头 | 内容和动作 |
|---|---|---|
| 0.000–5.000 | 品牌开场 | 终端光标转为紫色纵深 LHH，与 FESCO 一起落位。 |
| 5.000–10.033 | 动态标语 | Here → for you → 让用工问题 → 有 → 据 → 可 → 循，收成「有据可循」。 |
| 10.033–13.233 | 试用期考核 | 从一份 HR 的试用期考核记录切入，把具体情境带入下一镜的提问。 |
| 13.233–16.967 | 提问与检索 | 输入「试用期能否随意辞退员工？」。终端查找相关条款。 |
| 16.967–21.200 | 一条答复，可查依据 | 五张三维蓝色玻璃片沿轴分层，对应问题、回答、法规、案例和人工咨询。 |
| 21.200–24.933 | 咨询前，理清事实 | 局部故障字槽逐项呈现录用条件、考核记录、沟通时间、待问事项。 |
| 24.933–29.167 | 高频用工场景 | 试用期管理、薪酬与加班、劳动关系解除三个主题收成「有据可循」，两个入口展开。 |
| 29.167–32.900 | 法律法规库 · 案例库 | 对开资料册。左侧按《劳动合同法》条号定位，右侧用公开案例「拒绝违法加班被辞退」对照解除理由和录用条件。 |
| 32.900–43.000 | 依据汇流 · 咨询摘要 | 问题描述、法规依据、相关案例沿支流进入同一主线。汇聚成可阅读的咨询摘要，用户可选择转人工咨询。 |
| 43.000–48.833 | 法律及咨询顾问团队 | 公开示例用四张编号卡演示顾问轮播与最后一组的选中反馈。 |
| 48.833–53.067 | 三步开始咨询 | 三张卡在斜俯桌面轮流抬升、落影。「打开微信小程序」「注册账户」完成后，第三张「用工问题 直接问」悬起。 |
| 53.067–56.800 | 立即咨询 | 从品牌行动号召进入提问，提交后的界面反馈衔接白色品牌定版。 |
| 56.800–66.167 | 品牌定版 | 紫色 LHH 与标语就位，环绕字标继续旋转并渐缓，在原曲尾奏中稳定收住。 |

## SME 效果怎样转为 LHH 内容

| SME 视觉技术 | 原 LHH 镜头 | 本版处理 |
|---|---|---|
| 固定字槽、RGB 分离、局部水平错带 | 音频波形与 BPM | 每次干扰只在主字槽出现，随即恢复可读的咨询准备项。 |
| 低机位支流透视、曲线按弧长运动、终端接收反馈 | 银河、铬字与粒子球等独立作品 | 每条流线对应一种资料。中央收成同一个问题的咨询摘要，接顾问团队。 |
| 斜俯镜头、卡身厚度、抬升与双层投影 | 三张普通信息卡 | 卡片的起落表示操作顺序；第三张悬起，观众的视线落到「直接问」。 |

另将作品预览改成试用期考核材料，绘制代码改成法规与案例对照，收藏动作改成提交咨询。
